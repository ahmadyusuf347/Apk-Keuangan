# Catatan Keuangan
- `backend/` : Node.js + Express + PDFKit (`npm install && npm start`, port 3000). Deploy ke VPS/Render/Railway.
- `mobile/`  : React Native + Expo. Ubah `extra.apiUrl` di `mobile/app.json` ke URL backend Anda.
- Push ke GitHub (branch `main`) -> tab Actions -> unduh artifact APK.
